# ⚡ EV Charging Analytical Dashboard

## Project Overview

This project analyzes EV charging station performance, energy consumption, charging demand, revenue generation, and grid utilization across multiple global cities.

The dashboard was developed using Power BI to transform charging session data into actionable insights through interactive visualizations and KPI monitoring.

---

## Project Structure

📂 Raw Dataset

Contains the original EV charging dataset.

📂 Cleaned Dataset

Contains the cleaned and transformed dataset used for analysis.

📂 Dashboard and Report

Contains dashboard screenshots and Power BI report files.
